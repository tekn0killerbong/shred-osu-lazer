# Historical documents

Files kept here describe older prototypes and are retained only as historical context. They are not current build or installation instructions.

`FORMAT-SHRED-v1.txt`, when present, is the experimental first format description. `SHRED-MISE-A-JOUR.md`, when present, describes earlier implementation changes. Do not use their old absolute paths or judgement descriptions as the current v69 specification.

The reorganisation moves these documents only if they still exist locally. Previously deleted documents are not recreated. Old source copies and validation logs are kept outside the published documentation, under ignored `local/` directories.
